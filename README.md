## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `jmags-fashion` or `jmags29.github.io`).
2. Upload the entire contents of this folder (or push via git).
3. Go to **Settings → Pages**.
4. Under “Source”, select the branch (usually `main`) and folder `/ (root)`.
5. Save. Your site will be live at:
   - `https://username.github.io/repo-name/`  
   - or `https://username.github.io/` if you used the special `.github.io` repo name.

### Quick git commands
```bash
cd jmags-portfolio
git init
git add .
git commit -m "JMAGS Fashion Empire portfolio site"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

## Contact Form
The form currently points to a placeholder Formspree endpoint.  
To make it work:
1. Go to [formspree.io](https://formspree.io) and create a free form.
2. Replace `action="https://formspree.io/f/your-form-id"` in `contact.html` with your real endpoint.

Alternatively, visitors can simply use the WhatsApp link (recommended for fastest response).
